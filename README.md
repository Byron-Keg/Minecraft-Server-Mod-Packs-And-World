# Welcome to me and my friends Minecraft server! :)

## Modpacks

- Each release includes two modpacks labeled `Client` and `Server`.
- Import the `Client` `.mrpack` file into Modrinth (or another service with support for `.mrpack`)
- Extract the `Server` ZIP contents into your server's `mods` folder.

## World

- I upload the current state of our world every week.
- Each release includes a world snapshot and its corresponding modpacks.
